# autoplay-AI-agent

ระบบ AI ช่วยทีมซัพพอร์ตตอบลูกค้าผ่าน **บัญชี Telegram ของผู้ใช้เอง** พร้อมเว็บไซต์หลังบ้าน

- **เชื่อมบัญชี Telegram ของตัวเอง**: ผู้ใช้ใส่ API ID/Hash, เบอร์โทร, รหัสยืนยัน และรหัสผ่าน 2FA ผ่านหน้าเว็บหลังบ้าน
- **AI อ่านข้อความในกลุ่มลูกค้า**: เลือกได้ว่าจะให้ติดตามแชทไหน (รองรับข้อความและรูปภาพ)
- **ร่างคำตอบ แต่ต้องอนุมัติก่อนส่งทุกครั้ง**: แอดมินแก้ข้อความ, สั่ง AI เขียนใหม่, อนุมัติและส่ง หรือปฏิเสธได้ ถ้ายังไม่อนุมัติ ระบบจะไม่ส่งอะไรถึงลูกค้า
- **สรุปปัญหาเป็น Ticket**: AI จัดประเภทปัญหา เช่น เว็บไซต์ล่ม, เข้าสู่ระบบไม่ได้, ฝากเงินไม่ออโต้, ถอนไม่ได้ แล้วเขียนสรุปสำหรับโปรแกรมเมอร์ พร้อมรูปภาพจากลูกค้า ลิงก์เว็บไซต์ และไทม์ไลน์ข้อความ
- **ตรวจสอบเว็บไซต์อัตโนมัติ**: ถ้า ticket มีลิงก์เว็บ ระบบจะเช็กว่าเข้าได้ไหม (HTTP status และเวลาตอบสนอง)
- **สิทธิ์ผู้ใช้หลังบ้าน**: ผู้ดูแลระบบ / แอดมินตอบแชท / โปรแกรมเมอร์ (โปรแกรมเมอร์เห็นเฉพาะ ticket: รับงาน เปลี่ยนสถานะ บันทึกการแก้ไข)

## การทำงาน

```
ลูกค้าส่งข้อความในกลุ่ม Telegram
        │  (Telethon — บัญชีของผู้ใช้เอง)
        ▼
บันทึกข้อความ + ดาวน์โหลดรูป  →  รอลูกค้าพิมพ์ครบ (ค่าเริ่มต้น 15 วินาที)
        ▼
Claude วิเคราะห์บทสนทนา + รูปภาพ
        ├─► ร่างคำตอบ  →  หน้า "รออนุมัติ"  →  แอดมินกดอนุมัติ  →  ส่งเข้า Telegram
        └─► พบปัญหา    →  สร้าง/อัปเดต Ticket  →  ตรวจเว็บไซต์  →  โปรแกรมเมอร์แก้ไข
```

## ติดตั้ง

ต้องใช้ Python 3.10 ขึ้นไป

```bash
python -m venv .venv
.venv\Scripts\activate          # Windows  (macOS/Linux: source .venv/bin/activate)
pip install -r requirements.txt
copy .env.example .env          # macOS/Linux: cp .env.example .env
```

แก้ไฟล์ `.env`:

| ตัวแปร | ความหมาย |
|---|---|
| `ANTHROPIC_API_KEY` | คีย์ Claude API จาก https://platform.claude.com/ |
| `ADMIN_USERNAME` / `ADMIN_PASSWORD` | บัญชีผู้ดูแลระบบคนแรกของหลังบ้าน (สร้างครั้งแรกที่เปิดโปรแกรม) |
| `SECRET_KEY` | คีย์เข้ารหัสเซสชัน Telegram และคุกกี้ (เว้นว่างได้ ระบบจะสร้างให้ใน `data/secret.key`) |
| `HOST` / `PORT` | ที่อยู่เว็บหลังบ้าน (ค่าเริ่มต้น `127.0.0.1:8000`) |

รันโปรแกรม:

```bash
python run.py
```

แล้วเปิด http://127.0.0.1:8000

## เริ่มใช้งาน

1. เข้าสู่ระบบด้วย `ADMIN_USERNAME` / `ADMIN_PASSWORD`
2. ไปที่ **บัญชี Telegram** → ใส่ API ID และ API Hash (สร้างได้ที่ https://my.telegram.org/apps) พร้อมเบอร์โทร → ใส่รหัสที่ได้รับในแอป Telegram → ใส่รหัสผ่าน 2FA (ถ้ามี)
3. ไปที่ **แชทลูกค้า** → กด "ดึงรายชื่อแชทจาก Telegram" → เปิด "ติดตาม" เฉพาะกลุ่มลูกค้า
4. ไปที่ **ตั้งค่า** → ใส่ข้อมูลธุรกิจ ฐานความรู้ รายชื่อเว็บไซต์ของเรา และสไตล์การตอบ → เพิ่มบัญชีให้โปรแกรมเมอร์
5. เมื่อลูกค้าส่งข้อความ ร่างคำตอบจะขึ้นในหน้า **รออนุมัติ** และปัญหาจะถูกบันทึกในหน้า **Tickets**

## ความปลอดภัย

- **ไม่มีข้อความไหนถูกส่งถึงลูกค้าโดยอัตโนมัติ** ทุกข้อความต้องมีคนกดอนุมัติ และระบบบันทึกว่าใครอนุมัติ
- รหัสผ่าน Telegram (2FA) ใช้ตอนเข้าสู่ระบบเท่านั้น **ไม่ถูกบันทึก** ระบบเก็บเฉพาะ session ที่เข้ารหัสไว้ (Fernet) ในฐานข้อมูล
- ถ้ามีข้อความใหม่เข้ามาก่อนอนุมัติ ร่างเก่าจะถูกเปลี่ยนเป็น "ถูกแทนที่" เพื่อไม่ให้ส่งคำตอบที่ล้าสมัย
- การตรวจเว็บไซต์ถูกบล็อกไม่ให้ยิงเข้าที่อยู่ในเครือข่ายภายใน (กัน SSRF)
- ข้อมูลทั้งหมดอยู่ในโฟลเดอร์ `data/` (ฐานข้อมูล SQLite, รูปภาพ, secret key) ซึ่งไม่ถูก commit ขึ้น git
- ถ้าจะเปิดหลังบ้านให้เข้าจากภายนอก ควรวางไว้หลัง HTTPS reverse proxy (เช่น Nginx / Caddy)

> ⚠️ การใช้บัญชีผู้ใช้ (userbot) ผ่าน Telegram API ต้องเป็นไปตาม [Telegram API Terms of Service](https://core.telegram.org/api/terms) ควรใช้กับบัญชีของตัวเองเท่านั้น และไม่ควรส่งข้อความจำนวนมากในเวลาสั้น

## โครงสร้างโปรเจกต์

```
app/
  main.py              เว็บหลังบ้าน (FastAPI) และทุกหน้า/route
  telegram_service.py  เข้าสู่ระบบ Telegram, รับข้อความ, ส่งข้อความ (Telethon)
  analyzer.py          รอลูกค้าพิมพ์ครบ → วิเคราะห์ → สร้างร่างคำตอบ + ticket
  ai_service.py        prompt และการเรียก Claude (structured output)
  site_checker.py      ตรวจสอบสถานะเว็บไซต์
  database.py          โมเดลฐานข้อมูล (SQLAlchemy + SQLite)
  security.py          เข้ารหัส session, hash รหัสผ่านผู้ใช้หลังบ้าน
  templates/           หน้าเว็บ (Jinja2)
  static/style.css
run.py
```

## ปรับแต่ง

- **ประเภทปัญหา**: แก้ `CATEGORIES` ใน `app/ai_service.py`
- **โมเดล AI / ระดับการคิด / เวลารอ**: ตั้งได้ที่หน้า **ตั้งค่า** (ค่าเริ่มต้น `claude-opus-5-5`)
- **ใช้ฐานข้อมูลอื่น**: ตั้ง `DATABASE_URL` ใน `.env` (เช่น PostgreSQL)
